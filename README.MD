## Приложение для создания интернет магазина.

#### В данном приложении реализованы классы Category (для категорий товаров) и Product (для списка товаров)


### Установите зависимости:

```
poetry install
```

### Реализованный функционал:

1. Проверка отнесения продукта к категории товара, перед добавлением в категорию.
2. Проверка отнесения товаров к конкретной категории для подсчёта количества товара на складе.
